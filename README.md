# OUT OF PLACE: Playtest 0.5 (browser version)

**Play:** open the game page and click inside it to start.

OUT OF PLACE is a non-violent third-person stealth game: sneak in, take what you came for, and
get out unseen. This is an early **prototype**, so expect placeholder graphics and rough edges.
It has four missions: The Facility, Archive Complex, Blackout and Shapeshifter.

## Before you play

- **Use a desktop browser** (Chrome, Edge or Firefox) with a keyboard and mouse. Phones and
  tablets aren't supported.
- **The first load takes a moment:** the game is about 40 MB.
- **Click in the game** to capture the mouse. Pressing **Esc** frees the mouse and pauses the game.
- The browser version looks a little simpler than the downloadable one, and may run slower.

## Controls

| Action | Keyboard / mouse |
|---|---|
| Move / look | W A S D / mouse |
| Run (loud) | Shift |
| Crouch (quiet) | C |
| Interact / shapeshift (hold) | E |
| Aim and throw a distraction | Hold G, release to throw |
| Map | Tab |
| Pause, settings and missions | Esc |

- **Start any mission:** Esc → **Play Mission 01–04**.
- **Restart:** Esc → **Restart mission**, or **R** after you succeed or fail.

## The playtest log

The game keeps a small text log of each attempt **in your browser only**; nothing is sent
anywhere. To send it back: press **Esc → Download Playtest Log**, then attach
`playtest_log.txt` to your reply along with your answers below.
